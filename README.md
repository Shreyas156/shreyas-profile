# Shreyas Bhaginath Peherkar - QA Automation Portfolio

A modern, high-performance portfolio website for Shreyas Bhaginath Peherkar, Executive QA Engineer & Automation Specialist at IndiaMART InterMESH Ltd.

## Features
- **Hero Section**: Bio, metrics dashboard, tech stack pills.
- **Interactive QA & Automation Playground**: SEO Audit tool simulator & Auto Bug Logger.
- **Experience Timeline**: IndiaMART InterMESH Ltd achievements.
- **Skills Matrix**: Category-filtered skill grid with visual progress bars.
- **Resume Modal Drawer**: Full CV view with instant print/save PDF support.
- **Vercel Ready**: Clean URL routing & security header headers.

## Tech Stack
- HTML5, CSS3 (Glassmorphism, Dark Mode)
- Vanilla JavaScript
